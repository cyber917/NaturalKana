# SNS 词库

在唯一的「NaturalKana 设置」窗口打开「SNS 词库」。它帮助日语建议理解网络用语、保留原意；「词典」页则用于读音转词语，两者用途不同。

## 导入

1. 点击「保存 TSV 模板」，或使用 `examples/SNS词表模板.tsv`。
2. 用表格软件填写，再保存为 UTF-8 制表符分隔文本（TSV），不要直接改 XLSX 的后缀。
3. 点击「导入词表」，检查预览，再点「确认导入」。立即生效。同名词语更新，导入有格式错误时不修改原词库。
4. 可「导出词库」保存 JSON 备份。词条右键可以删除；搜索支持词语、读音、释义。

支持 TSV 和 JSON 数组，最多 2000 条、1 MB。TSV 表头对应关系：

| 英文列名 | 中文列名 | 要求 |
| --- | --- | --- |
| term | 词语 | 必填，实际要在日语句子中使用的词，最多 80 字 |
| reading | 读音 | 可选，最多 100 字 |
| meaning | 释义 | 必填，可用中文，最多 500 字 |
| example | 例句 | 可选，最多 300 字 |
| note | 用法 | 可选，最多 300 字；可标注语气、适用对象等 |
| source | 来源 | 可选，最多 300 字；建议记录书名、页码或网址 |

TSV 单元格不要包含换行或制表符。JSON 中只需要 term、meaning，其余字段可以省略。格式示例（自行编写，非书籍摘录）：

```json
[
  {
    "term": "推し",
    "reading": "おし",
    "meaning": "自己喜欢并支持的人或角色",
    "note": "理解原句的对象，不要擅自替换成恋人",
    "source": "个人整理，待校对"
  }
]
```

## 给建议时如何使用

只匹配当前草稿实际出现的词语；优先较长词语，最多八条，参考内容合计不超过 3000 字节。只有词语、释义、用法会随草稿发送，来源和整本词库不会发送。导入或删除词条后，旧建议缓存会失效。联网同意、受保护输入框、禁用应用和日语过滤规则仍然有效。

词条作为资料，不作为模型指令或已核实事实。原来的语体、俚语设置继续生效，不强行加网络腔，不把中文输入变成翻译请求。导入词库不是训练模型，也不保证每个模型都能正确理解；采用前仍可核对原意。

## 从书里整理

应用本版不能直接导入 PDF、照片或 XLSX。可以先从用户提供的内页/PDF 提取词语、释义和用法，校对读音、OCR 错字及中日对应关系，再生成 TSV/JSON。

整理中文网络用语时，请同时核对适合日语输入的表达和含义。书籍或网站内容需由词库维护者校对；个人整理的词库不应随项目源码公开上传。

## 响应速度

设置中可调整输入停顿等待。使用支持非思考模式的 Qwen 模型、关闭双服务商评选，通常能减少等待步骤。候选上限可调 1～10 条；生成更多候选可能需要更长时间。应用显示请求耗时和缓存命中状态，实际速度取决于模型、句子和网络。
