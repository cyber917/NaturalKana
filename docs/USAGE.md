# 配置与使用

[返回首页](../README.md) · [安装教程](INSTALLATION.md) · [SNS 词库](SNS词库使用说明.md)

## 第一次配置

只需要配置一家服务商。

1. **打开设置**：iPhone 打开 NaturalKana App → 设置 → 表达建议；Mac 在输入法菜单选“NaturalKana 设置…”→ 表达建议。
2. **打开开关**：“允许发送当前句子”和建议功能开关。iPhone 还要在系统键盘设置里给 NaturalKana 打开“允许完全访问”。
3. **选服务商**，填**接口地址**、**API 模型 ID** 和 **API 密钥**。
4. 点**保存设置**，再点**测试连接**。测试会发一条固定例句，可能产生少量费用。

注意：

- 模型要填 API 的模型 ID（比如 `qwen3.8-flash`），不是聊天界面里显示的名字；不要带空格或引号。
- 密钥要的是 API 密钥，不是网页版的登录密码。
- 保存后密钥框变空是正常的，密钥已存进钥匙串；之后留空保存会保留原密钥。
- 每家服务商的配置和密钥分开保存。Mac 和 iPhone 之间**不会同步**，要分别填写。

### 预设服务商

| 服务商 | 预设接口地址 | 协议 |
| --- | --- | --- |
| Qwen／百炼 | 国际站地址（中国站账户需改成控制台给出的地址） | OpenAI 兼容 |
| OpenAI | `https://api.openai.com/v1` | OpenAI 兼容 |
| DeepSeek | `https://api.deepseek.com/v1` | OpenAI 兼容 |
| Kimi | `https://api.moonshot.ai/v1` | OpenAI 兼容 |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | OpenAI 兼容 |
| Claude | `https://api.anthropic.com/v1` | Claude Messages |
| 自定义 | 自己填 | 在“接口兼容”里选 |

Qwen 的中国站和国际站、不同地域的密钥与地址必须对应，以[百炼控制台](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)为准；用 Qwen 时建议打开“非思考模式”，速度更快。

自定义接口支持 OpenAI **Chat Completions** 和 **Claude Messages** 两种协议，可以填 `/v1` 这样的基础地址，也可以填完整的 `/chat/completions` 或 `/messages` 地址。只支持 Responses API 或 Gemini 原生协议的接口不能用。

接口地址一般要用 `https://`。本机或局域网里自己搭的模型服务（Ollama、llama.cpp、vLLM 等）也可以直接填 `http://`，例如 `http://localhost:11434/v1`、`http://192.168.1.20:8080/v1`、`http://myserver.local/v1`。可以用 HTTP 的地址只有 `localhost`、`*.local`、不带点的主机名，以及 `127.x`、`10.x`、`172.16–31.x`、`192.168.x`、`169.254.x` 网段；其他地址仍然必须用 HTTPS。HTTP 不加密，草稿和密钥都会明文传输，只在可信的网络里用。第一次连接局域网地址时，系统可能会弹窗请求“本地网络”权限，要点允许。

## 日常使用

选择 NaturalKana 键盘，打一句日语并完成假名／汉字转换，光标停在句尾，停顿一下就会出现建议。

| 操作 | iPhone | Mac |
| --- | --- | --- |
| 看建议 | 键盘顶部卡片，左右翻页 | 光标旁的候选窗 |
| 采用 | 点句子 | 点候选，或 Control + 1 / 2。微信、Pages 等不支持直接替换的应用里，点候选会复制它，再选中原句按 ⌘V 粘贴 |
| 关闭 | 点 `×` | Esc |
| 移动 | — | 按住候选窗左上角的 ☰ 拖动，以后会记住这个位置；双击 ☰ 恢复默认 |

句子里夹着英文或中文词也可以，例如 `あとでmeetingがあるから、少し待って。`

### 切换建议语言

在“表达建议 → 表达 → 建议语言”里选日语、英语、中文、韩语、法语或俄语，再点**保存设置**。几种语言共用同一套服务商和密钥，默认是日语。Mac 和 iPhone 要分别设置。Mac 输入法本身能打日语和英语，其他语言用菜单栏小助手检查；iPhone 键盘还能开启韩语、法语和俄语布局，见下文。

选**自动**就不用来回切换：每一句都会自动判断是哪种语言。

- 有平假名的是日语。
- 有韩文字母的是韩语。
- 有俄语字母的是俄语；法语根据 je、vous、bonjour 等常见词判断。
- 有“的、了、吗、我、你、这”这类常见中文字的是中文。
- 英文句子是英语。

分不清的句子（例如只有汉字的短句“東京駅到着”）会按“主要语言”处理。主要语言是日语时，这种句子不会被当成中文。

### 界面语言

NaturalKana 自己的界面可以用**中文、English、日本語**显示，在设置最上面的“界面语言”里切换，默认跟随系统。

- **iPhone／Mac**：选完立刻生效，不用点“保存设置”。Mac 输入法菜单里的“NaturalKana 设置…”下次打开菜单时也会换成新语言。
- **Windows**：切换后设置窗口马上变成新语言，点**保存**后托盘菜单和建议卡片也会跟着变。

翻译覆盖 NaturalKana 新增的部分：表达建议设置、状态提示、建议卡片、SNS 词库、Mac 设置窗口和整个 Windows 版。azooKey 原有的 iPhone 键盘设置保持原样。英文和日文翻译还需要母语者校对，发现不自然的地方欢迎反馈。

- **日语**：Mac 用 `NaturalKana（日本語）`（图标「な」），iPhone 用日语键盘。
- **英语**：Mac 用 `NaturalKana (English)`（图标「na」），iPhone 在 NaturalKana 键盘里切到 `ABC` 布局。切到系统自带的英文键盘不会出建议。

“建议语言”决定检查和输出哪种语言，键盘布局决定怎么打字，两者要对应。英语建议按 Casual／Polite 分组。可以用这几句试试：`Yesterday I go to school.`、`Can you explain me how to use this?`、`I need to 预约 a table for two.`

### 中文建议

给学中文的人（比如身边的日本朋友）用：打一句中文，NaturalKana 给出更自然的说法，按**口语／礼貌**分组，只输出**简体中文**（大陆说法）。

- **iPhone**：NaturalKana 键盘打不了中文。先用**系统自带的中文键盘**（拼音、手写都可以）打完一句，再点 🌐 切换到 NaturalKana 键盘，就会读取这一行并给出建议，点一下即可替换。
- **Windows**：用任何中文输入法打字，选中句子按快捷键，或打开自动建议，和日语用法一样。
- **Mac**：用[菜单栏小助手](#mac-菜单栏小助手)。用拼音等任何输入法打完一句，按 ⌃⌥J 检查。

能处理的情况：

| 草稿 | 建议 |
| --- | --- |
| `我明天有工作，所以请等一点我` | 我明天要上班，你等我一下。（口语）／我明天要上班，麻烦您稍等一下。（礼貌） |
| `我昨天在コンビニ买了饮料` | 我昨天在便利店买了饮料。（句子里夹着日语、英语词也行） |
| `这个手紙是给你的` | 这封信是给你的。（会注意日语汉字和中文意思不同的词） |

- 繁体字或日本汉字会改成简体，候选里不会出现假名或繁体字。
- **网络用语**沿用“关闭／轻度／流行”三档：“轻度”只用“超、靠谱、搞定”这类常见口语；“流行”会在口语候选里用“绝了、破防、摆烂”等网络用语，并参考内置的中文网络用语词库。礼貌候选不会用网络用语。
- 内置中文网络用语词库约 40 条，还没经过人工逐条核对，所以和日语词库一样，只在“流行”档使用。
- 原句已经很自然时会显示小勾，不会硬改。

### 韩语建议

给学韩语的人用：分组是 **반말**（朋友之间的说法）和 **존댓말**（礼貌说法，해요체），只输出韩文。会修正助词（은/는、이/가、을/를）、词尾、空格，把句子里夹的英语、中文、日语词换成韩语；网络用语同样按“关闭／轻度／流行”三档。

- **Mac**：用[菜单栏小助手](#mac-菜单栏小助手)，用系统韩语输入法打完一句按 ⌃⌥J。
- **Windows**：用系统韩语输入法打字，按快捷键或打开自动建议。
- **iPhone**：在“表达建议 → 表达”里打开**键盘加入韩语布局**并保存。之后点语言键按快捷切换顺序进入韩语，也可以长按语言键后滑动选“한국어”。全键盘和九宫格英文位置的语言键操作相同。布局是标准两套式（두벌식）；没有 Shift 键，长按 ㅂㅈㄷㄱㅅ 后右滑输入 ㅃㅉㄸㄲㅆ，长按 ㅐㅔ 后右滑输入 ㅒㅖ。边打边出建议，和日语一样。

例句和提示词还需要韩语母语者审核。

### 法语、俄语建议与 iPhone 布局

在“建议语言”里选**法语／俄语**，或选“自动”。Mac 用系统键盘输入后按 ⌃⌥J 调出菜单栏小助手；Windows 用系统对应语言键盘输入后检查。

iPhone 在“表达建议 → 表达”打开**键盘加入法语布局**或**键盘加入俄语布局**，然后保存设置。键盘布局与建议语言分开设置：布局负责打字，建议语言负责检查。

- 打开**快捷切换语言**，选择平时要切换的语言，用上下箭头调整顺序，返回后点**保存设置**。例如只选韩语、俄语，点一下语言键就能韩俄来回切；选日、英、韩、法、俄五种，就按自选顺序循环。可选任意数量，至少保留一种。
- **长按语言键后滑动选择**，可以直接跳到任何已开启的语言，不必挨个切。没加入快捷切换的语言也在长按菜单里；长按不滑动会留在当前语言。从列表外的语言点一下，会进入快捷列表的第一种。
- 全键盘左侧语言键与九宫格原 ABC 键采用同样的切换规则。键面显示当前语言和下一种语言；日语、英语仍使用你原来选择的九宫格或全键盘布局。
- 默认使用全部已开启语言；旧设置保持日 → 英 → 已开启额外布局的顺序。自选快捷列表以后，新开启的布局先出现在长按菜单里，是否加入快捷切换由你决定。点“使用全部已开启语言”可恢复自动包含全部。
- 法语采用 **QWERTY**。长按并右滑选择：a → à â æ，e → é è ê ë，i → î ï，o → ô œ，u → ù û ü，c → ç，y → ÿ。所有字母及重音字母的大写也在长按菜单里。
- 俄语采用 **ЙЦУКЕН**，三排是 йцукенгшщзх／фывапролджэ／ячсмитьбю。长按 е 后右滑选 ё，长按 ь 后右滑选 ъ；所有字母的大写也在长按菜单里。
- 数字和标点通过 `123` 键输入，点语言键返回刚才的额外布局。法语、俄语直接输入，不经过韩语组字。
- 升级后会保留原来的韩语开关。没有自选快捷列表且未开启额外布局时，日英切换照旧。

法语候选按 **Familier／Poli** 分组，俄语按 **Разговорно／Вежливо** 分组；保留原句的人称、时态、否定、语气及称呼关系。例句：`Tu peux me dire c'est où la gare ?`、`Я завтра идти на работу.`。法语的字母与英语重叠，当前使用保守的常见词检查，没有这些词的短句可能不会送检；自动判断也可能有误。

**法语、俄语的提示词和例句需要母语者审核。** 两个包的 `lexicon.jsonl` 暂为空，等待审核后的词条，不宣称已验证网络用语。

### 方言（関西弁）

在“表达建议 → 表达 → 方言”里选**関西弁**，再点**保存设置**（只在建议语言是日语时显示，默认关闭）。打开后，候选里除了カジュアル／丁寧，还会多一组**関西弁**，标准日语照常给出：

| 草稿 | カジュアル | 丁寧 | 関西弁 |
| --- | --- | --- | --- |
| `今何にしていますか` | 今何してる？ | 今何してますか？ | 今何してるん？ |
| `昨日友達を会いました` | 昨日友達に会った。 | 昨日友達に会いました。 | 昨日友達に会ってん。 |

- 原句已经是自然的标准日语时，只显示関西弁一组，告诉你关西话怎么说。
- 関西弁候选和其他候选一样要保持原意、语气和礼貌程度；“语体”选了只要敬语时，関西弁也会是礼貌的说法。
- 関西弁候选也算在“建议上限”里。上限设为 1 时可能只有标准日语，想同时看到关西话请设为 2 条以上。
- **直接用方言打字也没问题**：不管这个开关开没开，`明日雨やったら行かへん` 这类正确的方言都不会被当成错误“纠正”成标准语，只修改真正写错的地方。
- 方言说法由模型生成，例句还没经过关西母语者完整审核；用在正式场合前最好再确认一下。

状态小图标：**小勾**表示模型认为不用改；**转圈**表示正在请求；**叹号**表示请求失败；**问号**表示没有可用建议或当前输入不支持。点（iPhone）或悬停（Mac）可以看详情。

### Mac 菜单栏小助手

Mac 输入法只能检查通过 NaturalKana 打出的字。**菜单栏小助手**（NaturalKana Helper）补上这一块：用任何输入法（拼音、系统日语、英文……）在任何 App 里打完一句，按 **⌃⌥J**（Control+Option+J），就会检查光标所在的这一行。日语、中文、英语都可以，建议语言选“自动”最方便。

- 光标停在句子里或句尾即可；选中一部分文字时，只检查选中的部分。
- 弹出建议后，按数字键 1～9 或点一下就替换回去；按 Esc 关闭。
- 有些 App（例如部分聊天软件）不提供输入框里的文字。这时请先选中这一句（例如 ⌘A 或 ⌘⇧←）再按 ⌃⌥J，小助手会用复制、粘贴的方式处理，并在用完后恢复你原来的剪贴板。
- 密码输入框不会被检查。
- 菜单栏的对话气泡图标里可以：检查当前句子、打开设置（就是输入法的设置窗口，两边共用同一份设置和每日请求上限）、设置登录时自动启动、退出。

第一次使用需要两次授权：

1. 按提示打开“系统设置 → 隐私与安全性 → 辅助功能”，打开 **NaturalKana Helper**。小助手要靠这个权限读取和替换别的 App 里的文字。
2. 第一次请求时，系统会问是否允许 NaturalKana Helper 使用钥匙串里的 API 密钥，输入开机密码后点 **始终允许**。

一键安装脚本会自动装好小助手（放在“个人 → 应用程序”里）。手动安装见[安装说明](MAC_INSTALL.md#第-11-步可选菜单栏小助手)。

## 常用设置

| 设置 | 说明 |
| --- | --- |
| 语体 | 口语、敬语或两种都要 |
| 网络用语 | 建议里网络用语的程度 |
| 界面语言 | 跟随系统、中文、English 或日本語 |
| 建议语言 | 自动、日语、英语、中文、韩语、法语或俄语；选“自动”时还要选“主要语言” |
| 方言 | 关闭或関西弁；打开后另给一组関西弁说法（仅日语），见上面的“方言” |
| 建议上限 | 1～10 条，是上限，不保证每次都有这么多 |
| 停顿 | 停止输入多少毫秒后请求，300～600 比较合适 |
| 每日请求上限 | 应用自己的次数限制，0 表示不限；不是服务商的费用上限 |
| 双模型评选 | 两家服务商各生成一次再评选，每次最多 3 个请求，更慢也更贵；初次使用建议关闭 |
| 使用快速设置 | 一键改成 300 毫秒停顿、关闭双模型评选，点完要保存 |

“接口兼容”里的协议、JSON 格式、输出长度参数、随机度，只在接口报参数错误时再调整。

## 没有建议时按这个顺序排查

1. 在设置里点**测试连接**。这里报错就先解决 API 配置。
2. 确认两个开关已打开并**保存**。
3. 确认当前用的是 NaturalKana 键盘（Mac 要选 NaturalKana（日本語），不是系统自带的日语）。
4. iPhone：确认已打开**允许完全访问**。
5. 用备忘录测试，完成转换、光标在句尾、停顿一下。密码框等受保护的输入框不会请求。
6. 看状态图标的详情；检查句子是否太短、是否超过每日上限。

| 报错 | 处理 |
| --- | --- |
| HTTP 401 | 密钥错误或失效，或密钥和接口地址的地域不匹配 |
| HTTP 403 | 账户没有这个模型或接口的权限 |
| HTTP 404 | 接口地址或模型 ID 写错 |
| HTTP 400／422 | 参数不被接受。依次尝试：JSON 格式改成 Object → 仅提示词；换输出长度参数；关闭随机度。每次改一项再测 |
| HTTP 429 | 额度或频率限制，稍后再试 |
| 连接失败／超时 | 检查**这台设备**到接口地址的网络、代理或 VPN |
| 返回格式不符 | 该模型不按约定返回 JSON，换模型或调整 JSON 格式 |
| 保存失败／读不到密钥 | 主程序和键盘的签名或共享配置不一致。iPhone 可在 设置 → 高级设置 里点“检查共享权限” |

## 数据与隐私

输入转换在本地完成。联网建议只发送当前句子（最多 200 字）、表达偏好和命中的词库条目，直接发给你配置的服务商，本项目没有服务器。开启双模型评选时会发给两家服务商。API 密钥保存在设备钥匙串里。公开截图前请遮住密钥。
