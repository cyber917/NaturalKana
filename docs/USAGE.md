# 配置与使用

[返回首页](../README.md) · [安装教程](INSTALLATION.md) · [SNS 词库](SNS词库使用说明.md)

## 第一次配置

只需配置一家服务商。使用 Qwen 不需要同时填写 OpenAI 密钥。

1. **打开设置。** Mac：选择 NaturalKana 输入法 → 输入法菜单 →「NaturalKana 设置…」→「日语建议」。iPhone：打开 NaturalKana 应用 →「设置 → 日语建议」。
2. **启用建议。** 打开「允许发送当前句子」和「日语建议」。iPhone 还需在系统键盘设置开启 NaturalKana 的「允许完全访问」。
3. **选择服务商。** 已有哪家的 API 密钥，就先选哪家。
4. **填接口地址。** 以该密钥对应的控制台地址为准，特别注意地域和 API 协议。
5. **填 API 模型 ID。** 从服务商的 API 模型列表复制，不能填聊天软件里的展示名称，也不要加空格、引号或说明文字。
6. **填密钥。** 在服务商控制台创建或获取 API 密钥，填写到密钥框。
7. **保存并测试。** 点「保存设置」，再点「测试连接」。底部会显示结果和耗时；测试会发送一条固定例句，也可能计费。

保存后密钥输入框变空是正常的，密钥已经存入设备钥匙串。之后**留空保存会保留原密钥**；想清除时使用「高级设置 → 删除当前服务商密钥」。不同服务商分别保存配置和密钥。

Mac 与 iPhone 的配置不自动同步，两端分别填写。先让「测试连接」成功，再排查实际输入时的建议。

### Qwen / 百炼示例

| 项目 | 怎么填 |
| --- | --- |
| 服务商 | Qwen / 百炼 |
| 接口地址 | 从百炼控制台或官方文档复制该业务空间、地域对应的 OpenAI 兼容地址 |
| API 模型 ID | 填账号可调用的实际模型 ID，例如已验证的 `qwen3.8-flash`；以当前账号开放的模型为准 |
| 密钥 | 填上述地域和业务空间对应的 API Key |
| 非思考模式 | 先开启；所选模型需支持该参数 |
| 双模型评选 | 初次配置先关闭，只用一家服务商 |

应用预填的 Qwen 地址是国际接口起点，**不表示适合所有账户**。中国站和国际站、不同地域的密钥及地址需要匹配。当前官方也提供带业务空间 ID 的地址；不要把文档里的 `{WorkspaceId}` 占位文字原样填进应用。地址选择见 [Qwen OpenAI 兼容文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。

JSON 格式先用「自动」。若模型不支持 JSON Schema，再按该模型的文档调整；不同 Qwen 型号的结构化输出支持不同，见 [Qwen 结构化输出说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。

### OpenAI 示例

服务商选择 OpenAI，官方接口地址为 `https://api.openai.com/v1`。在 [OpenAI API 密钥页面](https://platform.openai.com/api-keys)创建密钥，再从 API 模型列表选择账号实际可调用的模型 ID。可参考 [OpenAI API 入门](https://developers.openai.com/api/docs/quickstart)。

这里需要的是 **API 密钥和 API 模型 ID**，不是 ChatGPT 登录密码，也不是 ChatGPT 或 Codex 界面显示的模型名称。若旧密钥无法查看完整内容，可创建一把新密钥后更新应用。

### 其他服务商与自定义接口

以下是应用的预设地址。账户可能使用不同地域或网关；控制台提供了不同地址时，请按账户配置修改。

| 服务商 | 预设接口地址 | 协议 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | OpenAI 兼容 |
| Kimi | `https://api.moonshot.ai/v1` | OpenAI 兼容 |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | OpenAI 兼容入口 |
| Claude | `https://api.anthropic.com/v1` | Claude Messages |
| 自定义 | 自己填写 | 在「接口兼容」里选择 |

自定义接口的配置顺序：

1. 选择「自定义」，填 HTTPS 接口地址、该接口提供的模型 ID 和密钥。
2. 展开「接口兼容」，选择接口实际使用的协议。
3. OpenAI 兼容接口可以填 `/v1` 一类的基础地址，也可填完整的 `/chat/completions` 地址；Claude Messages 可以填 `/v1` 或完整 `/messages` 地址。
4. JSON 格式、输出长度参数先保持自动；遇到参数不支持的报错，再按接口文档调整并测试。

“支持 OpenAI”不一定表示所有协议都兼容。本版实现的是 **Chat Completions** 和 **Claude Messages**；只提供 Responses API 或 Gemini 原生协议的接口，不能直接按同一种协议使用。Gemini 请用上表的兼容入口。

不要把官网首页、控制台网址、模型聊天页填成接口地址。使用第三方网关时，确认密钥和接口属于同一家网关。

## 日常使用

选择 NaturalKana（日语模式），输入当前句子，完成假名／汉字转换，将光标留在句尾，停顿后查看建议。还在罗马字组合输入或转换过程中时，不要把暂未显示建议当成 API 故障。

可用下面的句子测试混合词语处理；它们是日语草稿中夹了不熟悉的英文词，不是整段翻译命令：

```text
いえいえー、clickしたらpasteをできる。
このfileをdownloadしてから、もう一回試してみて。
あとでmeetingがあるから、少し待って。
```

模型会尝试保留原意并生成日语表达。它可能认为某句不需要改，实际候选数量也可能少于上限。

| 操作 | Mac | iPhone |
| --- | --- | --- |
| 查看建议 | 光标附近的独立候选窗 | 键盘顶部卡片，左右翻页 |
| 采用建议 | 点候选；前两条默认可用 Control + 1 / 2 | 点候选句子 |
| 关闭建议 | Esc 或窗口的 `×` | 卡片的 `×` |
| 查看状态详情 | 悬停小图标；设置页也有状态文字 | 点小图标 |

关闭后，同一草稿不会立刻重新弹出；继续编辑后可以再次获取建议。关闭不要求先复制句子。

安全替换依赖宿主应用的输入上下文。iPhone 建议在句尾采用；Mac 无法可靠确认替换范围时，会复制候选并提示手动选中原句粘贴。请先在备忘录验证，再测试常用聊天软件。

### 小图标是什么意思

| 状态 | 含义 |
| --- | --- |
| 小勾 | 模型明确判断当前句子无需修改；不代表绝对无误 |
| 省略号 | 等待输入停顿 |
| 转圈 | 正在请求建议 |
| 叹号 | 请求失败，查看详情中的错误原因 |
| 问号 | 没有可用建议、当前草稿不支持或宿主上下文不可用，需要查看详情 |
| 没有图标或卡片 | 可能尚未触发、功能关闭、输入被本地规则拦截；到设置查看状态 |

“没有可用建议”和“本身无需修改”是不同状态。离线、接口失败、返回格式异常不会用小勾表示成功。

## 设置怎么选

| 设置 | 作用与使用建议 |
| --- | --- |
| 语体 | 口语用于朋友聊天；敬语用于较礼貌的表达；两种会分组展示，口语优先 |
| 网络用语 | 调整建议的网络用语程度；不想主动加网络腔就关闭或选轻度 |
| 标出改动 | 在候选里突出与原句不同的部分；本地计算，不额外调用模型 |
| 建议上限 | 1～10 条；是最多显示数量，不保证每次生成满额 |
| 停顿 | 停止输入后等待多少毫秒再触发；较短更早开始，但连续输入时更容易被取消重发 |
| 最少字符 | 太短的片段不请求模型；短句总是不触发时检查这一项 |
| 每日请求上限 | 应用限制当日请求次数；0 表示不限，不是免费或服务商的扣费上限 |
| 双模型评选 | 两家生成后再评选，每次最多 3 个请求；更耗时且可能增加费用 |
| 使用快速设置 | 停顿改为 300 毫秒、关闭双模型评选；当前使用 Qwen 时开启非思考模式；点完仍需保存 |
| 禁用应用 Bundle ID（Mac） | 在指定应用中不请求建议；填写应用标识，多个以逗号分隔 |
| 候选快捷键（Mac） | 修改前两条候选的 Control 组合键 |

初次使用可从口语或两种、3～5 条建议、300～600 毫秒停顿、关闭双模型评选开始。模型生成更多文本通常需要更久；把停顿调小，只会更早开始请求，不能直接加快服务商的推理。

### 接口兼容选项

这些选项只在接口不兼容时调整，正常工作时保留默认值即可。

| 选项 | 用途 |
| --- | --- |
| 协议 | 选择 Chat Completions 或 Claude Messages，必须与接口一致 |
| JSON 格式 | 自动按服务商选择；Schema 用结构约束，Object 用 JSON 输出模式，仅提示词不发送 `response_format` 参数 |
| 输出长度参数 | 有些接口使用 `max_tokens`，有些使用 `max_completion_tokens`；按模型文档选择 |
| 设置随机度 | 默认不主动发送 temperature；模型拒绝此参数时关闭 |

“仅提示词”能避免不支持 `response_format` 的接口报错，但模型仍必须按应用约定返回可解析 JSON，不能保证任何聊天接口都能使用。

## 词典和 SNS 词库

Mac 设置中的「词典」用于**读音 → 词语**的输入转换；「SNS 词库」用于给模型提供**词语含义与用法**，帮助保留网络用语的原意。

Mac 的导入步骤：打开「SNS 词库」→「导入词表」→ 检查预览 →「确认导入」。支持 TSV 和 JSON 数组；字段格式、模板和限制见 [SNS 词库使用说明](SNS词库使用说明.md)。当前 iPhone 设置页没有同样的词表导入入口，Mac 导入的个人词库也不会自动传到手机。

导入词库不是训练模型。正常 API 调用也不会自动上网搜索新词；应用仅把当前句子命中的少量词条作为参考发给模型。PDF、照片或整本书需要先整理成支持的词表，不能直接作为词库导入。

## 没有建议时按这个顺序排查

1. **先测连接。** 在应用设置里点「测试连接」。若这里就报错，先处理 API 配置，暂时不用反复打字。
2. **检查开关并保存。** 「允许发送当前句子」「日语建议」应开启，修改后点「保存设置」。
3. **确认输入源。** Mac 选 NaturalKana（日本語），不要选 Apple 的 Japanese；iPhone 长按地球键选 NaturalKana。
4. **检查手机完全访问。** 主应用联网成功不等于键盘有联网权限。
5. **完成转换并在句尾停顿。** 用备忘录测试，避开密码、网址、号码等受保护或不支持的输入框。
6. **查看状态详情。** 小勾表示不用改；叹号表示请求错误；本地检查未通过表示这次没有联网。
7. **检查阈值与限制。** 句子是否太短、是否超每日上限、Mac 当前应用是否被禁用；较长段落也不要当作单句直接测试。
8. **仅某个应用失败时。** 先记录宿主应用与版本，再在备忘录对照测试，可能是宿主没有提供足够上下文。

日语里夹少量中英文词可以处理；整段外语、翻译指令或模型指令不会因此变成支持的日语草稿。

### API 报错对照

| 错误或现象 | 怎么处理 |
| --- | --- |
| 缺少密钥或模型 | 填写当前选中服务商的密钥和 API 模型 ID，保存后再测 |
| 模型 ID 格式不正确 | 从控制台复制真实 ID，删掉空格、引号和展示名 |
| HTTP 401 | 检查密钥是否正确、是否有效，以及密钥和接口地域是否匹配 |
| HTTP 403 | 检查模型或接口权限，账号是否允许使用该服务 |
| HTTP 404 | 检查接口路径和模型 ID；不要用控制台网页地址代替 API 地址 |
| HTTP 400 / 422 | 参数被拒绝；核对 JSON 格式、输出长度参数、temperature 和 Qwen 非思考参数的支持情况，每次改一项再测 |
| HTTP 429 | 检查服务商额度或速率限制，等待后再试；连续点击不会解决限流 |
| HTTP 5xx | 服务商出错，稍后再试 |
| 连接失败或超时 | 检查当前设备到 API 地址的网络；电脑能访问不等于手机也能访问，分别核对代理、VPN 和地域 |
| 返回内容不符合格式 | 模型或网关没有按约定返回 JSON；核对该模型的结构化输出支持，不要仅凭偶尔成功判断已经兼容 |
| 未通过本地检查，未联网 | 本次草稿没有发送；查看文字是否是日语草稿、是否还在组合输入、是否包含翻译或指令内容 |
| 保存失败或找不到已保存密钥 | 核对签名和钥匙串共享配置；手机主应用与 Keyboard 必须使用一致的 Team 和共享组 |

OpenAI 兼容接口的 400 报错常见检查顺序：先核对模型 ID，再按接口文档尝试 JSON Schema → JSON Object → 仅提示词；然后核对输出长度参数，并关闭不支持的随机度。每次测试都会发请求，不要一次乱改所有选项。

## 数据与隐私

输入转换在本地进行；联网表达建议会发送当前句子（最多 200 字）、表达偏好和命中的词库参考。不会为了建议自动发送整段聊天或整本词库。启用双模型评选时，会向两家服务商发送请求。

API 密钥保存在设备钥匙串。服务商对请求数据的处理仍按其政策执行。不要向项目作者发送密钥、签名证书或私人词库；公开截图前遮住这些内容。
